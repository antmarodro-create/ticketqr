# 🎫 TicketQR

SaaS de venta de entradas con control de acceso por QR para eventos.

- Panel web para organizadores
- PWA lectora para porteros (QR + semáforo de validación)
- Dashboard de afluencia en vivo

## Estructura
- `supabase/` — esquema, funciones y seguridad de la BD
- `docs/` — resumen del proyecto y decisiones de diseño
- `src/` — aplicación Next.js (en construcción)
